Anmeldung ist nicht nötig: Auf dem Startbildschirm „ALS GAST SPIELEN“ wählen, dann eine Spielart. Für eine kurze Runde „Einzelspieler“, Schwierigkeit „Leicht“, „ÜBUNG STARTEN“.

Das freiwillige Konto mit E-Mail-Adresse wird über den Code aus der Anmeldemail bestätigt, der Link in der Mail öffnet die Webversion des Spiels.

Mehrspieler läuft über Supabase Realtime. Mit nur einem Gerät füllt die Option „Mit CPU auffüllen“ das Feld mit CPU-Panzern.

Das Spiel ist privat und nicht kommerziell, ohne Werbung, ohne Käufe und ohne Tracking. Es steht in keiner Verbindung zur Bundeswehr oder zu den Fahrzeugherstellern.

English: No sign-in is needed. On the start screen choose "PLAY AS GUEST" (the game follows the device language, English or German), then a game mode. For a short round choose "Single player", difficulty "Easy", start the battle.

The optional account with an e-mail address is confirmed with the code from the sign-in mail, the link in the mail opens the web version of the game.

Multiplayer runs on Supabase Realtime. With only one device, the option "Fill with CPU" fills the field with CPU tanks.

The game is private and non-commercial, with no ads, no purchases and no tracking. It has no connection to the Bundeswehr or to the vehicle manufacturers.
